01

Project Overview

This project compares a boundary-layer model with numerical solution results from ANSYS Fluent for flow around a circular cylinder, emphasizing model assumptions and predicted boundary-layer separation.

Engineering tools and methods: MATLAB, ANSYS Fluent.

02

Methodology

1.

Modeling and formulation

Formulated an implicit finite-difference solution of the boundary-layer equations.

2.

Numerical implementation

Solved the algebraic systems with the Thomas algorithm (TDMA) in MATLAB.

3.

Analysis and comparison

Performed a Navier–Stokes flow simulation using ANSYS Fluent.

4.

Interpretation and reporting

Compared the predicted separation angle and selected velocity profiles.
